# Excel_Sales_Dashboard
## 📌 Project Description

This project is an interactive Sales Dashboard created using Microsoft Excel to analyze and visualize sales performance.

The dashboard provides insights into total sales, total profit, total orders, quantity sold, average discount, regional performance, product performance, customer segments, and salesperson performance.

## 🎯 Key Objectives

- Analyze overall sales and profit performance
- Identify top-performing products and salespersons
- Compare sales across different regions and categories
- Analyze customer segments and sales channels
- Track sales trends over time
- Create an interactive and easy-to-understand business dashboard

## 🛠️ Tools & Techniques

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Excel Formulas
- Data Cleaning
- Data Analysis
- Dashboard & Data Visualization

## 📈 Dashboard Features

- Total Sales KPI
- Total Profit KPI
- Total Orders KPI
- Total Quantity KPI
- Average Discount KPI
- Top Salesperson
- Sales Over Time
- Sales by Category
- Sales by Region
- Top 10 Products by Sales
- Sales by Customer Segment
- Top 10 Salespersons

## 🔍 Interactive Filters

The dashboard includes interactive filters for:

- Order Date
- Region
- Category
- Product
- Salesperson
- Sales Channel
- Customer Segment
